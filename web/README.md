# Consultorios web

React + TypeScript (Vite) client for the Consultorios API.

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173 (proxies /api to http://localhost:5088)
npm test
npm run build
```

Start the API first (`http://localhost:5088`). Demo users are `*@demo.local`; passwords live only in `.env`.

UI copy is Spanish. Code and this README are English.
